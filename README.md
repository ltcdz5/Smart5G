# Smart 5G Switch

一个自动切换数据网络来省电的 KernelSU 模块。

> 手机在 5G 信号弱时，网速可能还不如 4G，耗电反而更高——因为它要不停搜网、重连。
> 这个模块在合适的时机自动切到 4G，条件恢复后再切回 5G，全程静默无弹窗。

本模块从作者自编内核的附加模块中抽离而来。

---

## 特性

- **三个触发条件**：高温（≥40℃）、低电（≤20%）、弱信号（RSRP <-100 dBm）
- **自动恢复**：温度、电量、信号都满足条件后自动回 5G
- **静默切换**：用系统接口实现，无提示框、无重连弹窗
- **WebUI**：Material You 风格界面，支持日间/夜间主题，参数可视化调整
- **低开销**：内存约 1.8 MB，后台每 120 秒检查一次，CPU 占用近似为 0
- **主动探测**：回落到 4G 后每 10 分钟临时放开 5G 测一次信号，信号变好立刻回切，不用干等
- **防抖动**：切换冷却期 + 阈值间隔约束，避免信号边缘反复横跳
- **充电感知**：充电时电池发热属正常，只有超过独立阈值（默认 45℃）才按高温回落

## 安装

1. 下载 [Releases](https://github.com/ltcdz5/Smart5G/releases) 里的 zip
2. 在 KernelSU 管理器中刷入
3. 重启

装好后不需要任何配置，模块会自动开始工作。

想调整参数的话，在 KernelSU 管理器里打开模块的 WebUI，或者在 `/data/adb/smart5g.conf` 里直接改。

---

## 兼容性

- 需要 **KernelSU**（已在 KernelSU 3.3.1 上测试）
- 需要系统支持 `cmd phone set-allowed-network-types-for-users`
- 已在 realme GT5 Pro（RMX3888 / SM8650 / Android 16）上验证
- 其他 ColorOS / realme UI 机型理论可用，未逐一测试
